# Документация Cpp2IL

Добро пожаловать в документацию проекта Cpp2IL - инструмента для реверс-инжиниринга Unity IL2CPP приложений.

## Обзор

Cpp2IL - это мощный инструмент для преобразования скомпилированных Unity IL2CPP приложений обратно в управляемые DLL. Проект находится в активной разработке и переписывании с целью создания более модульной и расширяемой архитектуры.

## Основные возможности

- ✅ **Поддержка множественных платформ** - Windows, macOS, Linux, Android, iOS, WebAssembly
- ✅ **Система плагинов** - расширяемость функциональности
- ✅ **Слои обработки** - гибкая обработка данных
- ✅ **Замена Mono.Cecil** - переход на AsmResolver.DotNet
- 🔄 **ISIL** - промежуточный язык для унификации анализа
- 🔄 **Control Flow Graph** - анализ потока управления

## Быстрый старт

### Установка

1. Скачайте последнюю сборку с [GitHub Actions](https://nightly.link/SamboyCoding/Cpp2IL/workflows/dotnet-core/development/)
2. Распакуйте архив
3. Убедитесь, что установлен .NET 9.0 Runtime

### Базовое использование

```bash
# Анализ Windows игры
Cpp2IL-Win.exe --game-path=C:\Path\To\Your\Game

# Анализ Android APK
Cpp2IL-Win.exe --game-path=game.apk

# С подробным логированием
Cpp2IL-Win.exe --game-path=C:\Game --verbose
```

### Просмотр возможностей

```bash
# Список доступных слоев обработки
Cpp2IL-Win.exe --list-processors

# Список доступных форматов вывода
Cpp2IL-Win.exe --list-output-formats
```
