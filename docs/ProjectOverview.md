# Обзор проекта Cpp2IL

## Описание проекта

Cpp2IL - это инструмент для реверс-инжиниринга Unity IL2CPP приложений, который преобразует скомпилированные бинарные файлы обратно в управляемые DLL. Проект находится в стадии активной разработки и переписывания.

## Текущее состояние проекта

### ✅ Реализовано

1. **Замена Mono.Cecil на AsmResolver.DotNet**
   - Полностью завершена замена зависимой библиотеки
   - Устранены ограничения Mono.Cecil
   - Улучшена производительность и стабильность

2. **Система плагинов**
   - Полностью реализована архитектура плагинов
   - Поддержка динамической загрузки плагинов
   - Реализованы плагины:
     - `Cpp2IL.Plugin.BuildReport` - генерация отчетов о сборке
     - `Cpp2IL.Plugin.ControlFlowGraph` - создание графов потока управления
     - `Cpp2IL.Plugin.OrbisPkg` - поддержка PlayStation форматов
     - `Cpp2IL.Plugin.Pdb` - поддержка PDB файлов
     - `Cpp2IL.Plugin.StrippedCodeRegSupport` - поддержка обфусцированного кода

3. **Поддержка множественных платформ**
   - Windows (x86/x64)
   - macOS
   - Linux
   - Android (APK)
   - iOS (IPA)
   - WebAssembly
   - PlayStation (через плагин)

4. **Система обработки (Processing Layers)**
   - `AttributeInjectorProcessingLayer` - инъекция атрибутов
   - `CallAnalysisProcessingLayer` - анализ вызовов
   - `StableRenamingProcessingLayer` - стабильное переименование
   - `NativeMethodDetectionProcessingLayer` - обнаружение нативных методов
   - `DeobfuscationMapProcessingLayer` - деобфускация
   - `AttributeAnalysisProcessingLayer` - анализ атрибутов

5. **Форматы вывода**
   - `AsmResolverDummyDllOutputFormat` - генерация dummy DLL
   - `DiffableCsOutputFormat` - C# код для сравнения
   - `IsilDumpOutputFormat` - дамп ISIL кода
   - `WasmNameSectionOutputFormat` - секции имен для WASM
   - `WasmMappingOutputFormat` - маппинг для WASM

### 🔄 В процессе разработки

1. **ISIL (Instruction-Set-Independent Language)**
   - Базовая архитектура реализована
   - Поддержка основных операций
   - Требуется доработка анализа и оптимизации

2. **Control Flow Graph (CFG)**
   - Базовая структура графов реализована
   - Требуется интеграция с ISIL
   - Нужна доработка алгоритмов анализа

### ❌ Не реализовано

1. **Полный анализ на основе ISIL**
   - Анализ потока данных
   - Оптимизация кода
   - Восстановление высокоуровневой логики

2. **Расширенная поддержка обфусцированных файлов**
   - Автоматическое обнаружение обфускации
   - Алгоритмы деобфускации
   - Поддержка шифрованных метаданных

## Архитектура проекта

### Основные компоненты

1. **Cpp2IL** - главное приложение (CLI)
2. **Cpp2IL.Core** - основная библиотека с API
3. **LibCpp2IL** - низкоуровневая библиотека для работы с IL2CPP
4. **Плагины** - расширяемость функциональности

### Ключевые классы

- `Cpp2IlApi` - основной API для работы с библиотекой
- `ApplicationAnalysisContext` - контекст анализа приложения
- `Cpp2IlPluginManager` - управление плагинами
- `InstructionSetRegistry` - реестр наборов инструкций

### Поддерживаемые наборы инструкций

- x86 (32-bit)
- x64 (64-bit)
- ARMv7
- ARM64
- WebAssembly

## Заключение

Проект находится в активной разработке с фокусом на создание более модульной и расширяемой архитектуры. Основные компоненты уже реализованы, но требуется доработка системы анализа на основе ISIL и CFG.
