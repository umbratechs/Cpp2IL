# ISIL (Instruction-Set-Independent Language)

## Обзор

ISIL (Instruction-Set-Independent Language) - это промежуточный язык, разработанный для унификации представления кода различных архитектур процессоров. Это ключевой компонент новой архитектуры Cpp2IL, который позволяет анализировать код независимо от конкретного набора инструкций.

## Цели ISIL

1. **Унификация** - единое представление кода для всех поддерживаемых архитектур
2. **Анализ** - упрощение анализа потока данных и управления
3. **Оптимизация** - возможность применения оптимизаций на высоком уровне
4. **Расширяемость** - легкое добавление поддержки новых архитектур

## Архитектура ISIL

### Основные компоненты

```
┌─────────────────┐    ┌─────────────────┐    ┌─────────────────┐
│   Disassembly   │───►│   ISIL Builder  │───►│   ISIL Code     │
│  (x86, ARM, etc)│    │                 │    │                 │
└─────────────────┘    └─────────────────┘    └─────────────────┘
```

### Ключевые классы

#### 1. InstructionSetIndependentInstruction
Основной класс для представления инструкции ISIL:
- `OpCode` - код операции
- `Operands` - операнды инструкции
- `FlowControl` - информация о потоке управления
- `Condition` - условие выполнения

#### 2. InstructionSetIndependentOpCode
Перечисление всех поддерживаемых операций:
- Арифметические операции (`ADD`, `SUB`, `MUL`, `DIV`)
- Логические операции (`AND`, `OR`, `XOR`, `NOT`)
- Операции сравнения (`CMP`, `TEST`)
- Операции перехода (`JMP`, `CALL`, `RET`)
- Операции работы с памятью (`LOAD`, `STORE`)
- Операции работы со стеком (`PUSH`, `POP`)

#### 3. InstructionSetIndependentOperand
Базовый класс для всех типов операндов:
- `RegisterOperand` - регистры
- `ImmediateOperand` - константы
- `MemoryOperand` - адреса памяти
- `MethodOperand` - ссылки на методы
- `StackOperand` - элементы стека

## Примеры использования

### Преобразование x86 в ISIL

```x86
mov eax, 42
add eax, ebx
cmp eax, 100
jge label1
```

Преобразуется в:

```isil
LOAD eax, 42
ADD eax, ebx
CMP eax, 100
JMP_GE label1
```

### Преобразование ARM64 в ISIL

```arm64
mov x0, #42
add x0, x0, x1
cmp x0, #100
b.ge label1
```

Преобразуется в тот же ISIL код:

```isil
LOAD x0, 42
ADD x0, x0, x1
CMP x0, 100
JMP_GE label1
```

## Интеграция с Control Flow Graph

ISIL код используется для создания графов потока управления:

1. **Блоки базовых блоков** - последовательности инструкций без переходов
2. **Узлы графа** - представляют базовые блоки
3. **Ребра графа** - представляют переходы между блоками
4. **Анализ потока** - анализ путей выполнения
